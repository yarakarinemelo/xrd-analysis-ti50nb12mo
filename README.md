# Análise por Difração de Raios X da Liga Ti-50Nb-12Mo

Este repositório contém o código-fonte desenvolvido para a análise estrutural da liga Ti-50Nb-12Mo por meio de difração de raios X (XRD), utilizando a linguagem de programação Python e técnicas de inteligência artificial. O objetivo é fornecer uma abordagem aberta e reprodutível para a análise de biomateriais metálicos.
